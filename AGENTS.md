# Agent Guidelines

## Agent skills

### Issue tracker

Issues and specs live in local markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical roles mapped 1:1 (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout (`GLOSSARY.md` at root and `docs/adr/`). See `docs/agents/domain.md`.
